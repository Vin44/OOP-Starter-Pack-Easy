# Parking Access & Fee Quotation API — Practice Starter / Reference Project

* Java 17; Spring Boot 3.3.5; Maven; port 8081.
* Open the folder containing `pom.xml` in IntelliJ IDEA as a Maven project.
* Wait for dependencies to resolve (internet or a pre-populated Maven cache required the first time).
* Run `ParkingApplication.main()` or `mvn spring-boot:run`.
* Complete the TODO sections, create any missing classes specified in the accompanying question paper, then test using HTTP requests.
* Package the **entire** project (including `pom.xml` and `src`) for practice submission.
* This project is completely separate from the actual examination. Sample tasks do not predict the real assessment.
